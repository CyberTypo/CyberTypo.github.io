KEBIJAKAN PRIVASI APLIKASI DEKGAM

(Data Ekosistem Gampong Administrasi Maju)

Kebijakan Privasi ini dibuat untuk membantu Anda memahami bagaimana aplikasi DEKGAM mengumpulkan, menggunakan, mengelola, memproses, dan melindungi data serta hak akses Anda selaku pengguna layanan digital ekosistem gampong.

Ruang Lingkup Wilayah & Pengembangan Layanan:
Saat ini, aplikasi DEKGAM diperuntukkan secara khusus untuk lingkungan internal Gampong Keude Keumuneng, Kecamatan Idi Tunong, Kabupaten Aceh Timur. Namun, aplikasi ini dirancang secara modular dan skalabel guna dikembangkan serta melayani cakupan wilayah hukum administrasi gampong/desa yang lebih luas di masa mendatang.

1. Data Pribadi yang Kami Kumpulkan

Untuk mendukung kelancaran pelayanan administrasi surat-menyurat dan fitur interaksi desa, sistem memerlukan beberapa identitas resmi Anda, meliputi:

  • Informasi Identitas Utama: Nama Lengkap (sesuai KTP), Nomor Induk Kependudukan (NIK), dan Nomor Kartu Keluarga (KK).
  • Informasi Kontak Aktif: Nomor HP/WhatsApp aktif dan alamat Email.
  • Data Profil Pendukung: Tempat/Tanggal Lahir, Agama, Jenis Kelamin, Pekerjaan, Status Perkawinan, dan Dusun tempat tinggal.

2. Data Geospasial dan Pelacakan Lokasi (Geolocator)

Aplikasi DEKGAM menggunakan infrastruktur penentu lokasi perangkat (Geolocator API) untuk merekam koordinat geografis pengguna:

  • Sistem mengumpulkan data lokasi perkiraan (Approximate Location) dan lokasi akurat (Precise Location) Anda.
  • Data lokasi ini hanya diambil pada saat pengisian formulir khusus kependudukan, seperti validasi letak fisik pada pengajuan Surat Keterangan Kepemilikan Ternak atau pemetaan aset gampong guna mencegah pemalsuan klaim di dalam wilayah desa.

3. Akses Fitur Perangkat Keras (Hardware Accessibility)

Aplikasi DEKGAM meminta izin operasional ke beberapa fitur fisik pada perangkat handphone Anda demi mendukung fungsionalitas berikut:

  • Akses Kamera (Foto Dokumen): Digunakan untuk mengambil gambar dokumen pendukung secara langsung, melakukan pemindaian (scan) QR Code printer desa saat mencetak surat mandiri, serta dokumentasi kegiatan desa.
  • Fitur Beta AI OCR (Text Recognition): Kamera terintegrasi dengan teknologi Google ML Kit dan OCR Space API dalam status uji coba (Beta). Gambar KTP yang Anda foto akan diproses untuk mengekstrak data teks identitas secara otomatis ke dalam formulir pendaftaran guna mempercepat pengisian data.
  • Akses Galeri & Media Gambar: Digunakan saat Anda ingin memilih atau mengunggah berkas gambar/sertifikat yang sudah tersimpan di dalam handphone Anda ke dalam sistem pengajuan dokumen gampong.
  • Penyimpanan Lokal Perangkat (Shared Preferences): Aplikasi menggunakan memori lokal handphone untuk menyimpan token sesi masuk (login session) agar Anda tidak perlu melakukan autentikasi ulang setiap kali membuka aplikasi, serta menyimpan berkas foto kegiatan desa pilihan Anda.

4. Fitur Interaksi Sosial (Chat Global & Mading Desa)

Aplikasi ini menyediakan wadah komunikasi terbuka antarkomunitas warga gampong terdaftar:

  • Fitur Chat Global: Setiap pesan teks atau media yang Anda kirimkan di dalam ruang obrolan publik dapat dilihat oleh pengguna aplikasi lainnya. Kami mengimbau warga untuk tidak membagikan informasi rahasia atau data pribadi sensitif di dalam ruang obrolan publik ini.
  • Mading Desa (Majalah Dinding Digital): Informasi, pengumuman, atau berita kegiatan yang diunggah ke Mading Desa bersifat publik untuk seluruh warga. Sistem mencatat identitas akun (User ID) pengunggah demi menjaga akuntabilitas konten dan menghindari penyebaran berita palsu (hoax) atau ujaran kebencian.

5. Keamanan Akun, Otentikasi, dan Perlindungan Server

Kami berkomitmen penuh menerapkan standar keamanan tinggi untuk melindungi privasi data warga:

  • Metode Akses & Sandi Pertama: Pendaftaran akun divalidasi menggunakan NIK penduduk dengan kata sandi bawaan awal berupa Tanggal Lahir (DOB) pendaftar. Pengguna diwajibkan untuk mengubah kata sandi bawaan tersebut pada saat login pertama kali demi mengamankan privasi akun pribadi.
  • Enkripsi Dokumen Database: Di dalam server peladen, dokumen akun Anda dikunci menggunakan Firebase User ID (UID) acak yang terenkripsi, bukan menggunakan nomor NIK mentah Anda sebagai ID dokumen utama.
  • Perlindungan Server (Firebase App Check): Lalu lintas data database dilindungi oleh infrastruktur App Check guna memastikan hanya aplikasi DEKGAM resmi dan terverifikasi yang dapat mengakses peladen, serta memblokir akses ilegal atau serangan siber dari luar.

6. Manajemen Pengguna Berbasis Peran (Role-Based Access Control)

Akses terhadap basis data internal diisolasi secara ketat berdasarkan klasifikasi peran akun pengguna (Permission Checks):

  • Sistem membagi tingkat akses menjadi beberapa peran resmi dengan hak kelola yang berbeda, yaitu: Warga, Operator Surat, Keuchik (Kepala Desa), dan Developer (Pengembang Proyek).
  • Aturan keamanan server (Firestore Security Rules) memastikan warga tidak dapat mengintip atau mengubah data milik warga lainnya. Data pribadi sensitif hanya dapat diverifikasi oleh Operator Surat dan Keuchik yang sah demi keperluan administrasi desa.

7. Kendali Aktivitas Registrasi Oleh Admin

Pihak Administrator/Operator Gampong memiliki otoritas penuh melalui panel kontrol pusat untuk mengaktifkan atau menonaktifkan sistem pendaftaran mandiri warga kapan saja. Jika status pendaftaran dinonaktifkan, penduduk baru harus melapor langsung ke kantor gampong guna menjaga validitas data kependudukan riil di lapangan.

8. Siklus Hidup Data & Sistem Sampah Digital (Trash System)

Aplikasi DEKGAM menerapkan kebijakan pengelolaan hapus data sementara yang transparan (Soft Delete):

  • Every pengajuan surat administrasi yang dihapus oleh warga atau operator tidak langsung hilang permanen, melainkan diubah statusnya menjadi "deleted" di server.
  • Data berstatus hapus sementara tersebut akan disimpan di folder Sampah Digital gampong selama 7 (tujuh) hari untuk mengantisipasi kesalahan hapus tidak sengaja.
  • Setelah batas waktu 7 hari terlampaui, skrip otomatis peladen (Firebase Cloud Functions) akan mengeksekusi penghapusan seluruh data dan berkas tersebut dari server secara permanen.

9. Integrasi Layanan Pihak Ketiga dan Analitika

Dalam mengoptimalkan performa aplikasi, DEKGAM mengintegrasikan beberapa infrastruktur eksternal resmi milik pihak ketiga:

  • Google Firebase (Core, Auth, Firestore, Storage, Functions, Messaging): Untuk manajemen akun, database cloud, penyimpanan berkas surat, otomatisasi server, dan notifikasi pengajuan surat waktu-nyata melalui Firebase Cloud Messaging (FCM).
  • Firebase Analytics: Mengumpulkan data statistik perilaku penggunaan aplikasi secara anonim (halaman yang paling sering dikunjungi, durasi pemakaian, stabilitas sistem) demi bahan evaluasi dan peningkatan performa aplikasi ke depan.
  • Google Maps API: Untuk pemrosesan dan pemetaan data geospasial lokasi aset penduduk.
  • Google Apps Script & Google Drive: Digunakan sebagai mesin eksternal untuk menjahit data inputan formulir menjadi berkas cetak PDF surat resmi secara otomatis (tanpa nomor dan tanda tangan awal).

10. Hak Pengguna dan Transparansi Hukum

Sebagai pengguna, Anda berhak mengubah data profil secara mandiri, menonaktifkan toggle "Gunakan Data Profil Saya" jika ingin mengisi data orang lain, serta membatalkan draf surat kapan saja sebelum diverifikasi operator.

Pemerintah Gampong Keude Keumuneng berkomitmen penuh TIDAK AKAN PERNAH menjual, menyewakan, atau membocorkan data pribadi warga kepada pihak pengiklan swasta, broker data, atau pihak ketiga mana pun di luar kepentingan koridor hukum administrasi negara Pemerintah Kabupaten Aceh Timur.

11. Persetujuan Anda

Dengan melakukan registrasi akun dan menggunakan layanan aplikasi DEKGAM, Anda menyatakan telah membaca, memahami, dan memberikan izin penuh kepada perangkat gampong untuk mengolah data tersebut sesuai koridor Kebijakan Privasi ini demi kelancaran pelayanan publik kependudukan.
